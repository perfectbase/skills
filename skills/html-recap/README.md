# HTML Recap

Turns a completed work unit, pull request, branch, commit, or diff into an
interactive standalone HTML recap grounded in the actual changed lines.

It emphasizes visible behavior, contracts, architecture, file footprint, and
a focused set of load-bearing diffs.
